# Final Report

## Application Overview

This project is a professional Flask-based Earthquake Analytics Platform using open earthquake data.

## Key Features

- Multiple linked database tables
- Analytics dashboard
- Earthquake comparison
- Data visualization charts
- Search functionality
- Error handling
- Automated testing
- Responsive design

## Architecture

The project uses:
- Flask
- SQLAlchemy ORM
- Bootstrap
- Chart.js
- Service-layer architecture

## Testing

Pytest and coverage testing are included.

## Deployment

The application is deployment-ready for Render using Gunicorn.
